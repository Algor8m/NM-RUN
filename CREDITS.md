# NM Run credits and asset notes

- All project UI styles, procedural preview geometry, synthesized sound effects and camera effects in Person 4 files are original implementation created for this prototype.
- Three.js `0.180.0` is an open-source 3D library installed from npm. Review its license and package metadata before redistribution.
- Socket.IO Client `4.8.1` is an open-source networking library installed from npm. Review its license and package metadata before redistribution.
- Vite `6.4.1` is an open-source development/build tool installed from npm. Review its license and package metadata before redistribution.
- Google Fonts CSS references Barlow Condensed and Inter. The interface falls back to system fonts if the font service is unavailable. For fully offline deployment, bundle fonts only after reviewing their licenses and adding the files to the project.
- No external game artwork, campus photography, NMIMS logo, or copied game assets are included.
